研究切入点是 Spark 重复 action 与进度查询开销。材料包含研究新聊天中的实际提问、可见过程消息与三轮完整回答，不用摘要代替原文。只省略导出器生成的本地会话文件路径，实际对话不作改写。

报告基于 720 次受控状态源模型运行、35 次真实 Spark 正式对照及 35 次预实验。模型结果与实机测量分别标注，不声称自适应策略普遍更优。
